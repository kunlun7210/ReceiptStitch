# 收款拼图

一个可添加到 iPhone 主屏幕的网页 App。

使用网址：[收款拼图](https://kunlun7210.github.io/ReceiptStitch/)

项目源码：[kunlun7210/ReceiptStitch](https://github.com/kunlun7210/ReceiptStitch)
在设备本地识别银行卡尾号与可用余额 / 额度，先打马赛克，再将相邻两张照片横向拼接，最后添加平铺水印。

## 使用

1. 在 Safari 打开 https://kunlun7210.github.io/ReceiptStitch/ ，无需账号登录。
2. 点 Safari“分享”→“添加到主屏幕”，保留“作为网页 App 打开”。
3. 选取 2 张照片，或批量选择 4、6、8、10 张；每相邻两张组成一组。支持分次添加，最多 20 张。以相册返回的选择顺序排列，缩略图下方可前移、后移，也可交换一组的左右。
4. 等待识别，检查遮挡范围。点“检查左图 / 检查右图”可补框、删除框、撤销或放大查看。
5. 点“保存图片”或“保存全部”，在 iPhone 系统分享面板选择“存储图像”。不支持文件分享时提供下载或长按图片保存。

## 默认水印

- 内容：`机器/收款码办理 详询VX：kunlun7210`
- 字号：50 pt（画布按 96 px/in 换算为 66.67 px）
- 透明度：70%，即文字不透明度 30%；数值越高越浅
- 颜色：浅灰 `#b3b3b3`
- 方式：斜向 30° 平铺，在马赛克与拼接完成之后绘制

水印设置保存在当前浏览器。照片、OCR 文字和结果不持久化，关闭或重载页面会清空照片。生成的 PNG 不复制源文件的元数据。

字号和透明度均为可拖动滑块，实时显示 pt / 百分比；使用 4px 蓝色线条和 16px 蓝色圆点，没有手动字号输入。

设置按“颜色 → 透明度 → 字号”排列。第一排是红、黑、蓝、浅灰四种常用颜色，以及调色盘按钮；其他颜色收在调色盘的二级菜单，点开显示 6 列 × 5 行固定色板。默认勾选浅灰，无系统颜色器或色号输入。

## 识别与画面

- 支持“银行卡尾号”“银行卡号”“卡号尾号”“尾号”等写法，以及“可用余额”“可用额度”。处理每张图片内全部匹配字段。交易金额和其他内容不主动遮挡。
- 每张图先运行 PP-OCRv6-small，然后根据字段文字及同一行的相对位置确定遮挡区域。识别并非所有银行样式都能保证命中，输出前可手动补框。
- 遮挡区域使用完全不透明、与源内容无关的浅灰色块，并按实际数字的笔画边界收紧，四周保留少量边距。导出后不可从马赛克区域恢复原始像素。
- 等高横向拼接，保留完整画面与长宽比。不自动裁掉状态栏、广告或聊天记录。不同尺寸的图片按较高的一张等比例缩放。超大图限制至 1200 万像素和单边 8192 像素，界面会提示已适配尺寸。
- OCR 未完成时不能直接导出；可重试，或在两张图中分别手动框选并点“完成检查”后继续。

## 本地与离线

本工具只有静态网页，无图片上传接口、远程识别服务、统计脚本或外部 CDN。识别模型、JavaScript 和 WebAssembly 均由本站提供，图片仅送入当前浏览器的专用 Worker。

首次识别需下载约 79.7 MB 组件，下载过程中实时显示百分比、已下载 MB 和进度条，并校验 SHA-256 后缓存。准备完成后可断网重开并识别、拼图、导出。Safari 清理站点数据、系统回收缓存或首次使用另一个浏览器时需要重新下载。可在“使用说明”中提前准备离线识别。

为满足静态托管的单文件大小限制，WebAssembly 文件分成两段下载，在浏览器本地合并、验证原始 SHA-256 后缓存；合并后的二进制与原运行组件一致。

## 源码与验证

`dist/` 可直接作为 HTTPS 静态站点部署，不需要构建或运行服务器端程序。模型与运行组件沿用已有截图智能裁剪项目中的固定版本，包含第三方许可文本；原项目未修改。组件清单及 SHA-256 见 `dist/ocr/manifest.json`。

开发预览：运行 `npm run serve` 后，打开 [http://127.0.0.1:48721/](http://127.0.0.1:48721/)。该地址仅在运行预览服务的 Mac 上可用。本机测试服务器的 `/fixtures/` 路由仅用于读取测试素材，生产部署中不存在该服务器和路由。项目和部署目录均不含用户素材或已生成的金融截图。

测试：安装 `package.json` 中的开发依赖，设置 `SAMPLE_DIR` 指向含 `1.PNG` 到 `10.PNG` 对应素材的目录，然后运行 `npm run test:samples` 和 `npm run test:browser`。`BROWSER=webkit` 可测 WebKit。测试产物写入项目相邻的 `qa/`，不会打进站点。Chrome 测试使用已安装的 Google Chrome。

验证范围和结果随交付附在“验证说明.md”中。桌面 WebKit 通过不代表已在实体 iPhone 上测试相册、主屏幕安装或 iOS 分享面板。

参考：[PaddleOCR.js 官方 SDK](https://github.com/PaddlePaddle/PaddleOCR/blob/main/paddleocr-js/packages/core/README.md)、[WebKit 主屏幕 Web App 说明](https://webkit.org/blog/17333/webkit-features-in-safari-26-0/)。
