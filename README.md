# 遮图 · Zhetu

[打开遮图网页版](https://kunlun7210.github.io/zhetu/) · **v1.2（2026-11-08）**

智能隐私拼图。在手机或电脑的浏览器里，识别截图中的银行卡尾号、可用余额或额度，先遮挡，再按需要拼图、加水印，最后导出 PNG。照片和识别结果在设备上处理，无需登录。iPhone 用户可以在 Safari 的分享菜单中选择「添加到主屏幕」，作为网页 App 使用。

## 怎么用

1. **准备模型。** 第一次使用需要联网。可以在「模型信息」或右上角「？」里提前下载，也可以直接选图，等待模型自动准备。
2. **选择要处理的图片。** 单张可直接打码；多张默认合成一张横向拼图。可改为「逐张处理」或「自定义分组」，并调整组内顺序。
3. **检查遮挡。** 点照片或成品下方的检查控件。默认以 1× 铺满可用宽度，可用右侧滑动条查看长图，也可以切换到「整图」。漏遮处可手动框选，选择马赛克、纯色或涂抹，并可撤销或删除选区。
4. **保存成品。** 可调整水印内容、颜色、透明度和字号，再点「保存图片」或「保存全部」。iPhone 可在系统分享面板选「存储图像」；也可按页面提示长按预览或逐组保存。

## 八种拼图样式

| 样式 | 输出方式 |
| --- | --- |
| 横向、竖向 | 同组照片排成一条横排或竖排；默认横向。 |
| 双列网格、三列网格 | 按列排版，保留各张照片的完整画面。 |
| 竖向 6 张（2 列 3 行）、九宫格（3 列 3 行） | 分别按每张成品最多 6 张、9 张分页，最后一页的空位留白。 |
| 两张一组 · 横向、两张一组 · 竖向 | 手动选择后，按顺序将相邻两张拼成一组；最后一张落单时单独输出。切回常规样式后可继续使用原来的自定义分组。 |

横向、竖向没有固定的选图张数上限；单张成品超过约 1200 万像素或单边 8192 像素时会按比例缩小。

## 隐私与离线

- 自动识别针对银行卡尾号、可用余额和可用额度等字段，交易金额和其他信息需要按需手动遮挡。不同银行的截图样式可能识别不到，分享前请检查成品。识别失败时，可重试或手动检查并确认后再导出。
- 自动与手动遮挡均使用完全不透明、与原图无关的像素。每张原图先遮挡，再缩放和拼接，最后在成品上加水印；导出的 PNG 不复制原图元数据。
- 首次下载识别组件约 39.2 MB（支持 gzip 解压的浏览器）。模型和组件准备好后，浏览器保留站点缓存时可断网重开、识别及导出；清理站点数据或更换浏览器后需重新准备。
- 照片、分组和结果只保留在当前页面。水印、常规拼图样式和手动遮挡偏好保存在当前浏览器。

## 本地开发

`dist/` 可以直接部署为静态站点。运行 `npm run serve` 后，打开 [本地预览](http://127.0.0.1:48721/)；添加 `?source=origin` 可从本地站点加载识别组件。

识别组件采用 PP-OCRv6-small，下载及缓存会校验 SHA-256。分支、组件构建和测试命令见 [开发与验证](DEVELOPMENT.md)，组件版本与校验值见 [OCR 清单](dist/ocr/manifest.json)。
